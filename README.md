# Cloud Cost Intelligence Platform

http://localhost:5173

An AI-powered cloud analytics platform that monitors cloud spending, detects anomalies, forecasts future costs, and provides intelligent optimization recommendations.

---

## Features

- Cloud cost dashboard
- Spending analytics and charts
- AI-powered cost optimization recommendations
- Budget alert system
- Cost anomaly detection
- REST API backend
- Secure authentication system
- Docker support
- Responsive React frontend

---

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- Chart.js / Recharts

### Backend
- FastAPI
- Python
- REST APIs
- JWT Authentication

### Database
- SQLite (Demo)
- PostgreSQL (Production Ready)

### Cloud & DevOps
- AWS Cost Explorer API
- Docker
- GitHub Actions

- Vercel

### AI Features
- AI-generated cloud optimization suggestions
- Forecasting engine
- Cost anomaly detection
